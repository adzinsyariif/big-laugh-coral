Entry for the [One Line, Big Laugh](https://make.fun/bounty/u-coral-404-one-line-big-laugh-328fb857) bounty on make.fun: a program that writes a single hilarious line, 200 characters or fewer, that lands entirely on its own.

## The line

> I taught my parrot to say 'per my last email' in my voice, and HR promoted him over me.

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`), deterministically — two runs write identical bytes.
